## 3. What “complete topic coverage” means
For each syllabus unit and each examinable subtopic, record:
1. **Syllabus anchor:** exact unit/topic text and code.
2. **Concept:** definition, scope, essential elements, underlying principle and purpose.
3. **Background:** historical development, earlier doctrine, the problem it responded to, and intellectual context.
4. **Authorities:** verified primary legislation/constitutional provisions where relevant, leading cases, later treatment, dissent or criticism if significant.
5. **Case brief:** court/year/citation; material facts; issue; holding; ratio; why it matters; later status where verified.
6. **Change log:** earlier rule vs current rule, commencement date, savings/transitional notes; if there is no statutory provision, say “not a section-based topic”.
7. **Critique:** strengths, weaknesses, counter-theory and modern relevance.
8. **Application:** illustration, hypothetical/problem question and a structured answer.
9. **Exam material:** 4/5-mark short note; 10-mark short essay; 20-mark long essay; comparison questions; likely questions marked as predictions, never promises.
10. **Revision:** one-page recall sheet, flashcards, case/thinker table, mini-test and self-marking rubric.
11. **Research trace:** source URL, authority type, last checked date and uncertainty flags.

## 4. Common omissions to prevent
- Confusing 3-year LL.B. with B.A. LL.B. or a different university’s scheme.
- Learning the IPC while a cohort is examined on BNS, or vice versa.
- Memorising section numbers from an old edition without the current official text.
- Writing a case name without material facts, ratio, or connection to the issue.
- Treating a coaching-site “important question” list as university-confirmed.
- Missing counter-arguments, comparative distinctions, illustrations and conclusions.
- Confusing dicta, ratio, minority opinions and later treatment.
- Treating an old exam structure as guaranteed for the next sitting.
- Studying cases in isolation from the exact syllabus and prescribed books.
- Omitting constitutional/statutory amendments, commencement, applicability and saving provisions.
- Failing to practice answer time limits and the paper’s actual choice pattern.
- Over-relying on an AI summary without checking primary authorities.

## 5. Branch/version protocol
- Draft each substantial paper in a dedicated Git branch; merge after syllabus and authority review.
- Every content file states creation/update time (IST), legal-source check date, and status: Draft / Verified / Needs faculty confirmation.
- Use ISO dates: YYYY-MM-DD. Log why a change was made, not just what changed.
- In a law-change review, check the Gazette/India Code, commencement notification, amendments and relevant binding judgment.
- Mark case references “verification pending” rather than inventing a citation.
- Major statutory changes are maintained in a dedicated comparison table (for example IPC ↔ BNS) so older and current law are not mixed.
