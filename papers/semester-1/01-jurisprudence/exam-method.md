# Jurisprudence I — answer-writing method
**Created:** 2026-10-27 23:11 IST  
**Status:** Draft v0.1; adapt to official current paper instructions.

## A. Universal structure for a theory essay
1. **Direct introduction:** define the concept and state the thesis in 2–4 sentences.
2. **Context:** identify the school/thinker and the problem the theory addresses.
3. **Core doctrine:** explain each component using numbered subheadings.
4. **Authorities:** mention correctly named thinkers and their distinct contributions; give a case only when it illuminates the point.
5. **Example/application:** apply the theory to a simple legal situation or legal institution.
6. **Criticism:** identify at least two substantive strengths and two limitations; acknowledge a defence or response.
7. **Comparison:** distinguish the nearest competing theory if the question invites it.
8. **Conclusion:** give a reasoned answer to the actual question.

Do not begin with an unrelated quotation. A definition, map of the answer and accurate terminology are more valuable.

## B. Approximate depth by marks
Marks and time allocation must follow the instructions on the actual paper. These are writing guides, not official time limits.

### 4–5 marks: concise note
- One-sentence definition.
- 3–5 precise features/arguments.
- One key thinker or authority.
- One limitation or distinction if relevant.
- One concluding sentence.

### 10 marks: short essay
- Brief introduction and historical position.
- 4–6 explained headings.
- Correct theorist terminology.
- A concise critique and conclusion.
- Avoid writing the full biography of a thinker.

### 20 marks: long answer
- Define and frame the issue.
- Explain doctrine under logical headings.
- Give the theory’s components and intellectual context.
- Add a comparison table or structured contrast where useful.
- Evaluate with strengths, criticisms and a response.
- Give an accurately relevant illustration or case.
- End with a direct conclusion. Cover the question, not every fact you know.

## C. Comparison questions
A comparison answer should use the same axes for both theories:
| Axis | Theory A | Theory B |
|---|---|---|
| Central question | | |
| Source/validity of law | | |
| Role of morality | | |
| Law-making/recognition | | |
| Explanation of legal change | | |
| Main strength | | |
| Main criticism | | |

Then explain what the comparison establishes. Do not give two unrelated mini-essays.

## D. Case-law handling
A proper case note is: **case name + court/year/citation (if reliably known) + material facts + legal issue + decision + ratio + use in this answer**. Distinguish holding from incidental observations, majority from dissent, and binding authority from persuasive example. When a citation is uncertain, omit it rather than invent one.

## E. Self-assessment rubric (0–5 each)
- Relevance to the wording of the question
- Accuracy of definition and central thesis
- Completeness of doctrinal elements
- Accurate thinkers/authorities
- Critical evaluation (not just description)
- Comparison/application where useful
- Coherent structure and readable paragraphs
- Direct conclusion

A high-scoring answer is not necessarily the longest: it is accurate, responsive, logically organized and critically aware.

## F. Common answer-killers
- Claiming all positivists think morality is irrelevant in every sense.
- Reducing Austin’s theory to “law is whatever government says” without sovereign, command, duty and sanction.
- Treating Kelsen’s Grundnorm as an enacted statute or an actual written constitutional section.
- Treating Hart’s rule of recognition as identical to Austin’s sovereign.
- Confusing Savigny’s Volksgeist with a claim that all customs are necessarily just.
- Saying Maine’s “status to contract” means status has disappeared from modern society.
- Calling Pound’s social engineering unrestricted utilitarianism without explaining competing interests and social ordering.
- Equating Duguit’s social solidarity with a slogan without explaining social interdependence and the limits it places on public power.
- Reducing realism to “judges decide however they want”.
- Presenting Marx’s base/superstructure account as a complete description of every individual legal rule without noting debates and variation.
- Adding case names that do not actually support the point.
